# Code of Conduct

Este proyecto sigue un código de conducta para fomentar una comunidad abierta y acogedora. Se espera que todos los colaboradores sigan un comportamiento respetuoso.

Si detectas comportamientos que violen estas normas, por favor contacta al mantenedor del repositorio o abre un issue privado.

Para el texto completo y ejemplos, consulta: https://www.contributor-covenant.org/
